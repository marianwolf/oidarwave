# Implementierungsplan: Web Notifications

## Übersicht
Benachrichtigungen bei Titelwechsel mit "Jetzt läuft"-Info und Klick-Handler zum Öffnen der App.

## Dateien
- `src/js/player.js` - Haupt-Player-Logik erweitern
- `index.html` - UI für Benachrichtigungs-Einstellung hinzufügen

## Implementierungsschritte

### 1. Benachrichtigungs-Service erstellen
Neue Datei: `src/js/notifications.js`

```javascript
// NotificationService mit:
// - requestPermission() - Berechtigung anfordern
// - notify(title, artist, station) - Benachrichtigung senden
// - isEnabled() - Check ob aktiviert (localStorage)
// - toggle() - Ein-/ausschalten
// - Speicherung in localStorage: 'notificationsEnabled'
```

### 2. Player erweitern
`src/js/player.js` anpassen:

- `lastTrackTitle` Variable hinzufügen (vergleichen für Änderung)
- Bei Titelwechsel: `NotificationService.notify()` aufrufen
- Vorher prüfen: `NotificationService.isEnabled()`

### 3. UI-Element hinzufügen
`index.html` - Toggle-Button im Player-Bereich:
- Glocken-Symbol mit aktiv/inhaaktiv-Zustand
- `aria-label`: "Benachrichtigungen aktivieren/deaktivieren"

### 4. Focus-Funktion bei Klick
- Bei Klick auf Benachrichtigung: `window.focus()`
- Falls Tab im Hintergrund: zu diesem Tab wechseln

## Technische Details

### Notification API
```javascript
if (Notification.permission === 'granted') {
    new Notification('Titel', { body: 'Artist - Song', icon: '/favicon.svg' });
}
```

### localStorage Key
- `notificationsEnabled` (boolean)

### Browser-Support
- Fallback für Safari/ältere Browser
- Prüfung: `if ('Notification' in window)`

## Benutzer-Flow
1. User klickt auf Glocken-Icon
2. Browser fragt Berechtigung an
3. Bei "Erlaubt": Benachrichtigungen aktiv
4. Bei Titelwechsel → Benachrichtigung
5. Klick auf Benachrichtigung → App im Vordergrund

## Randfälle
- Titel bleibt gleich → keine Benachrichtigung
- Benutzer hat Benachrichtigungen blockiert → Button zeigen, aber deaktiviert
- Keine Metadaten → keine Benachrichtigung
- Tab geschlossen → Benachrichtigung trotzdem sichtbar (Browser-Level)
