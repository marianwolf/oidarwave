# Oidarwave

Ein modernes Webradio-Interface für deutsche und internationale Radiosender.

## 🎵 Über das Projekt

Oidarwave ist eine benutzerfreundliche Webradio-Anwendung, die es ermöglicht, verschiedene Radiosender direkt im Browser zu hören. Die Anwendung bietet eine saubere, minimalistische Benutzeroberfläche und unterstützt HTML5-Audio für optimale Wiedergabequalität.

## ✨ Features

- **Moderne Benutzeroberfläche**: Sauberes, responsives Design
- **Vielfältige Senderauswahl**: Auswahl verschiedener deutscher und internationaler Radiosender
- **HTML5-Audio**: Native Browserunterstützung für optimale Audioqualität
- **Offline-Erkennung**: Intelligente Behandlung von Verbindungsproblemen
- **Responsive Design**: Optimiert für Desktop und mobile Geräte

## 📻 Verfügbare Radiosender

Die Anwendung bietet folgende Radiosender:

- **Radio Paradise** - Internationale Musikvielfalt
- **Deutschlandfunk** - Öffentlich-rechtlicher Informationssender
- **Deutschlandfunk Kultur** - Kultur und Gesellschaft
- **Deutschlandfunk Nova** - Junges Programm
- **NDR 1** - Norddeutscher Rundfunk
- **NDR Info** - Nachrichten und Information
- **NDR 2** - Pop und Rock
- **NDR Kultur** - Klassik und Kultur
- **80s80s NDS** - 80er Jahre Musik

## 🛠️ Technische Details

- **Frontend**: HTML5, CSS, JavaScript
- **Audio**: HTML5 Audio API
- **Hosting**: Vercel
- **Responsive**: Mobile-optimiert

## 🎯 Verwendung

1. Besuchen Sie [https://oidarwave.vercel.app/](https://oidarwave.vercel.app/)
2. Wählen Sie einen Radiosender aus dem Dropdown-Menü
3. Klicken Sie auf Play, um die Wiedergabe zu starten
4. Verwenden Sie die integrierten Browser-Audiokontrollen zur Lautstärkeregelung

## 📱 Browser-Kompatibilität

Die Anwendung erfordert einen modernen Browser mit HTML5-Audio-Unterstützung:

- ✅ Chrome/Chromium (empfohlen)
- ✅ Firefox
- ✅ Safari
- ✅ Edge
- ❌ Internet Explorer (nicht unterstützt)

## ⚠️ Systemanforderungen

- Internetverbindung für Audio-Streaming
- Browser mit HTML5-Audio-Unterstützung
- JavaScript aktiviert

## 🔧 Lokale Entwicklung

Repository klonen
```bash
git clone [repository-url]
```
In das Projektverzeichnis wechseln
```bash
cd oidarwave
```
Lokalen Server starten (z.B. mit Python)
```bash
python -m http.server 8000
```
Oder mit Node.js
```bash
npx http-server
```

Anschließend die Anwendung unter `http://localhost:8000` aufrufen.
